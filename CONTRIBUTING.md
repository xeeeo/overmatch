# Contributing

Overmatch is built in the open. Issues, playtest reports and pull requests are welcome.

## Ground rules

- **Data over code.** Units, buildings, weapons, upgrades, powers and AI build orders live in `game/data/` as JSON. If a change can be a data change, make it one.
- **Sim stays engine-free.** `sim/` must not reference Godot. Anything that needs Godot lives in `game/`.
- **Every model has a script.** Models are generated by `tools/blender/*.py`. Do not commit hand-edited `.blend` files as the source of truth.
- **Tests for sim logic.** New sim behaviour comes with an xUnit test in `sim.tests/`.
- **No EA assets, names or text.** Overmatch is a spiritual successor, not a port.

## Workflow

1. `dotnet test sim.tests` must pass.
2. `godot --path game --headless --quit` must start cleanly.
3. Open a PR against `main`; CI builds macOS and Windows artifacts.
