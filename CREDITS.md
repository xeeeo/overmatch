## Inspiration

Overmatch is inspired by Command & Conquer: Generals – Zero Hour (EA Pacific / EA Los Angeles, 2003). EA released the Generals source code under GPL v3 in 2025 (https://github.com/electronicarts/CnC_Generals_Zero_Hour); it is consulted as a reference for game logic. No EA assets are used.
