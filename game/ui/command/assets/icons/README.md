# Command interface glyphs

Original vector artwork created for Overmatch, 2026. Licensed under **Creative Commons Attribution 4.0 International (CC BY 4.0)**, matching the repository's `LICENSE-ASSETS`. Credit: **Overmatch contributors**. No third-party game artwork is used.

The 19 SVGs share a transparent 64 × 64 canvas, warm ivory `#d4d8cd`, strong silhouettes, and limited translucent secondary marks. They are intended for command buttons at 36–48 pixels and larger faction badges. The UI may tint them to indicate selection, availability, and faction accent.

- Structures: `command`, `reactor`, `supply`, `barracks`, `factory`, `airfield`, `research`, `defense`, `satellite`.
- Orders and utilities: `repair`, `sell`, `stop`, `attack`, `rally`, `dozer`, `chevron`.
- Original faction emblems: `coalition` (precision wings), `directorate` (industrial shield), `network` (linked cells).

These are abstract UI glyphs. They do not replace world models, unit portraits, or faction gameplay definitions.
