# Bulwark — unit review 01

This is the first unit pass, based on `d4019b9` after M5 and the live UI adoption.
Only the Coalition Bulwark's visual asset changes. Its cost, HP, collision radius,
weapons, movement, abilities and other gameplay definitions remain unchanged.

## Direction

A low, broad hull and angular composite turret give the Coalition tank a clear
silhouette. Segmented skirts sit above visible running gear; a protected sight,
rear cooling vents and simple armour seams add detail without relying on textures.
Team colour sits on the turret cheeks, bustle and hull shoulders so it is visible
from above and when the turret turns. The art remains stylised and flat shaded.

The model is original work, licensed CC BY 4.0 under the repository asset license.
It uses no EA assets or external model parts. It is generated entirely from Python.

## Review

```bash
bash tools/art/review_bulwark.sh
```

This opens an isolated native Godot scene with the original and proposed GLBs at
identical scale and under identical lighting. The original snapshot in `assets/`
comes from `d4019b9`. It is only a reference and is never used by gameplay.

- **1 / 2 / 3:** blue, red and gold from the game's actual player palette.
- **T:** rotate the turret between 0° and 90° while keeping the hull fixed.
- **Z:** switch between close-up and normal RTS scale.

The RTS view reproduces a center crop of the 45° FOV, 32-unit-distance game camera
at a 1600×900 reference resolution. It uses studio lighting and floor rather than
the live terrain. There is no simulation in this review scene.

Optional arguments after the launcher select reproducible capture states:

```bash
bash tools/art/review_bulwark.sh --unit-team=red --unit-turret=90
bash tools/art/review_bulwark.sh --unit-scale=rts
bash tools/art/review_bulwark.sh --unit-capture=/absolute/path/comparison.png
```

## Regenerate the unit

```bash
blender -b -P tools/blender/build_models.py -- bulwark
# Or invoke its dedicated builder directly:
blender -b -P tools/blender/build_bulwark.py
```

Both routes generate only `game/assets/models/coalition/bulwark.glb`. The existing
`coalition_bulwark()` entry point delegates to the new dedicated builder; the other
unit builders and shared `omlib.py` are unchanged. The repository already tracks
an `omlib` Python bytecode file; Blender may rewrite it when importing the helper.
That generated bytecode is not part of this art change.

Studio renders use the actual exported geometry and materials. The renderer
applies the same blue team-colour substitution as the game. No raster edits or
generated concept paintings are used in these images.

```bash
blender -b -P tools/art/render_bulwark.py -- --mode hero --samples 32
blender -b -P tools/art/render_bulwark.py -- --mode comparison --samples 32
```

## Runtime contract and cost

| Property | Original | Proposed |
| --- | --- | --- |
| Triangles | 752 | 4,496 |
| Mesh nodes | Hull + Turret | Hull + Turret |
| Material surfaces | 6 | 14 |
| Team material | TeamColour | TeamColour |
| Turret pivot, Godot XYZ | (-0.15, 1.06, 0) | unchanged |
| X bounds | -1.15 to 1.52 | -1.158 to 1.511 |
| Y bounds | 0.09 to 1.61 | 0.055 to 1.5885 |
| Z bounds | -0.96 to 0.96 | -0.968 to 0.968 |

The existing 1.1 collision radius and selection behaviour are unchanged. The new
asset fits essentially the same envelope and retains +X forward, ground origin,
identity turret rest rotation and the exact `Turret`/`TeamColour` names consumed by
the engine. No muzzle/VFX, selection, camera or entity-rendering code is changed.

This pass increases geometry and material surface count for the art review. A large
battle performance benchmark has not been run; material consolidation is a possible
follow-up once the visual direction is approved.
