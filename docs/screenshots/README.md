# In-game screenshots

Captured on 17 October 2026 from game revision [`2f9db9d`](https://github.com/xeeeo/overmatch/commit/2f9db9d), using Godot 4.7.2 .NET and the production game renderer at 1920 × 1200 with 4× MSAA.

The faction images come from running skirmishes with the normal Hard AI controlling both sides, standard starting resources and normal game rules. A temporary capture driver selected buildings, moved the regular RTS camera and saved the viewport. It did not spawn extra forces or construct a separate display scene. Matches ran at 8× speed and briefly paused for capture. The HUD, models, terrain, production queues and effects are those used in the playable game.
